CHECK THE DEVICE先確認機器規格（30 秒）

  1. 看處理器與 vPro

    按 Win + Pause 或「設定 → 系統 → 系統資訊」，記下處理器型號；機身或包裝上的 vPro 標誌代表具備 Intel vPro。

  2. 看有沒有 NPU

    按 Ctrl + Shift + Esc 開啟工作管理員 →「效能」分頁，有 NPU 項目代表可以執行裝置端 AI。

  3. 確認是否為 Copilot+ PC

    鍵盤有 Copilot 鍵、NPU 40+ TOPS 的機型才有 Click to Do、Recall、即時字幕翻譯等專屬功能。拍下貼紙或規格，回台灣對照。

ASK THE TRAINER問主訓練師的問題（附預期答案）

先猜答案再展開。現場聽到的答案和這裡不同時，以主訓練師為準並記下來。

規格怎麼最快分辨一台機器是不是 Copilot+ PC？

預期答案：看 NPU 是否達 40+ TOPS、有沒有 Copilot+ PC 標示，以及 Click to Do 等專屬功能是否出現。鍵盤上的 Copilot 鍵不一定代表是 Copilot+ PC。

規格vPro 和非 vPro 的 Core Ultra，對 SMB 客戶最大的差別是什麼？

預期答案：遠端管理（Intel AMT 頻外管理）與 Intel Hardware Shield 的韌體層防護，以及為企業設計的穩定平台。對沒有 IT 的客戶，最有感的是遠端修復。

Demo哪一個功能在客戶面前最有「哇」的效果？

預期答案：多半是 Windows Studio Effects 的眼神校正與背景處理，以及 Click to Do。記下主訓練師的建議與示範順序，直接放進自己的 Demo。

DemoDemo 時網路不穩，哪些 AI 功能還能用？

預期答案：跑在 NPU 上的裝置端功能，例如 Windows Studio Effects、即時字幕等，不依賴雲端。Copilot 對話與 Microsoft 365 Copilot 需要網路。這是說明 NPU 價值的好例子。

通路經銷商要怎麼取得示範機？

預期答案：透過 Intel 或 OEM 的示範機計畫，或聯合行銷活動申請。記下窗口與申請條件，這是 90 天計畫中最重要的資源。

通路客戶最常問、最難回答的問題是什麼？

開放題。把主訓練師的答案記下來，加進第 1 天「探索提問」的異議處理清單。
